AI Accessibility Auditor

Check a page for access barriers, in plain language. The AI suggests fixes, you approve or reject each one — nothing is fixed without you.

How to use this product

  1. Run the audit — press “Run audit” to scan the sample page below. It lists the 8 issues it finds, each with a WCAG reference.
  2. You decide — approve, reject or skip each fix. Approving one applies it to the sample page live, and raises the score.
  3. Check the rest — some things need a real person and a screen reader. The summary lists exactly what is still unchecked.

Sample data only. No backend, no external AI calls, no real page is scanned, and nothing you do here is sent anywhere. This demo does not certify WCAG conformance.

        Still needs a human designer to check

        • Screen-reader test: run the fixed page with VoiceOver or NVDA — an audit cannot hear what a screen reader actually announces.
        • Keyboard-only walkthrough: Tab through the whole page. Check focus is visible, in a sensible order, and never gets trapped.
        • Alt text meaning: the auditor can check alt text exists, but only a person can tell if it actually describes the image well.
        • Real users: test with people with low vision and people who use assistive tech, on their own devices and settings.
        • Rejected items: anything you rejected above still needs a designer decision — either a different fix, or a documented reason it is OK as it is.
