Alt-Text Studio

Write alt text people can actually use. AI drafts it, shows its confidence, and you stay in control — no guessing, no invented names.

How to use this product

  1. Choose an image — pick one of the three samples below.
  2. Draft, then edit — tap “Draft alt text”, check the flagged guesses, and rewrite in your own words.
  3. Approve — pass all 4 WCAG checks, then approve and copy the final text.

Sample data only. No backend, no external AI calls. Nothing you type is sent anywhere.

3WCAG checklist — live

Updates as you type, toggle, or switch images. WCAG 2.2, Success Criterion 1.1.1 Non-text Content.

  • –Has alt text, or is marked decorativeInformative images need text. Decorative images should have empty alt (alt="").
  • –Length: 125 characters or fewerShort alt text is easier for screen readers. Current length is shown above the checklist.
  • –No “image of” / “photo of” redundancyScreen readers already announce it as an image — don’t repeat that.
  • –Names a person only if knownDon’t invent a name, age, or gender. Tick “known to me” above only if it’s true.
